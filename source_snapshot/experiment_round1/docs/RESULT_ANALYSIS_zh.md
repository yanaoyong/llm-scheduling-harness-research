## 维护阈值：实例08的第一次运行

| 方案 | 三台litho加工负荷 | 三台litho非初始维护耗时 | 最终makespan |
|---|---|---|---:|
| A | 53, 44, 53 | 23, 0, 23 | 159 |
| B | 50, 50, 50 | 0, 0, 0 | 118 |
| C | 47, 48, 55 | 0, 0, 23 | 114 |

该实例litho的wk维护阈值为50。B的50/50/50分配无需追加该维护，A的53/44/53触发两次23单位维护，这是与B较短排程一致的可观察结构。C保留一次追加维护仍取得114，说明避免维护次数本身并不是完整优化目标。此处是事后排程解释，没有做替换单一决策的因果实验。
