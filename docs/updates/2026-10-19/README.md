1. A/B 完整计划 384 题、16 请求完成。explicit 为 728/768（94.7917%），dense 为 699/768（91.0156%）；dense 平均输入少约 30.53%，但若干题类准确率较差，按事前规则选择 explicit。没有发现 earliest_start/nominal_start 数值混淆。历史网络失败尝试仍计入成本，未按零用量处理。
2. 先前 smoke 依次暴露动态边界、工具预算、非法任务引用和资格错配。通用自检修订后的首个 E1 smoke 与匹配 P2 均合法采纳。
