# 当前状态与续作边界

实际试验已停止并封存。本轮新增归档不授权再次调用模型。原 B 保持原状，后续开发若获批准应继续使用独立副本。

可以确认：已有任务可以跨轮保留并自动执行；扩大输入窗口实际带入了更多资料；有限预算下的初次分包已做离线验证。不能确认：总调用下降、长期排程质量提高、真实时钟下无接续等待或 2000 台真实机组可用。

下一轮讨论可围绕以下已出现的问题，而不是单纯要求模型多排任务：

1. **已排工序被另一台机组重复报为缺计划。** 逐机缺口检测与全厂已分配工序过滤使用了不同口径；部分提醒因此没有把关联工序完整装入输入。
2. **等待任务跨轮保留的时间语义。** 最早开工时间已过去但物料未到时，旧任务仍可能合理等待；当前编译规则却要求显式改写。不能把每次改写直接算成额外模型调用，应逐次追踪。
3. **查询历史的保留。** G0 在共同区间之后出现连续 10 次读资料，输入只展示部分任务且旧工具结果主要保留引用；这提供了进一步分析方向，不证明所有重读都不可避免。
4. **比较质量与完整成本。** 继续同时报告查询、提案、确认、失败、未排需求、等待和产出；不通过让任务积压或忽略失败降低表面调用。
5. **独立比较在线能力。** 当前模拟时钟在模型思考期间暂停，必须另设真实时延实验才可讨论模型是否赶得上接续截止。
