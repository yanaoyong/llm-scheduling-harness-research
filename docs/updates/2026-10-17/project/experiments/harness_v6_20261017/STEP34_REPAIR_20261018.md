## 步骤 4 压力预算结果

本次纯离线诊断参数：模型元数据标签 gpt-5.4、context=1,000,000、reserve=10,000、
MCP 3 次工具调用 / 4 次请求、wall=300 s、horizon=900、delta=60、delta_min=60。
这些参数**不是用户批准的生产预算或模型选择**。返回内容均由本地 mock 生成；
模拟 usage=100/20/10 只验证协议，不能当成真实模型计费量。

工具结果压力样本返回完整当前状态对象；不是生产 read_entities 的真实回答，也不是所有未来输出的数学上界。
计数继续采用序列化请求字段的保守口径，包含实际系统指令、工具表、完整历史、协议元数据与输出保留。
