## 写作依据与限制

- “第一次失败、第二次成功”无法唯一对应到具体运行版本，正文采用有记录的“全厂 B 停滞与多轮恢复”过程；第二个计划提交不等于第二次完整实验成功。
- 个人 Harness 以团队形式分发给公司人员，这一点有本人原话为证；改进案例来自自用验收。已查材料中没有同事反馈链、团队采用率或提效数据。
- 冷轧经历只引用可核实的职责，不展开具体规则案例。
- 排程项目尚未完成；现场规则共建和人员培训是入职后的计划。
