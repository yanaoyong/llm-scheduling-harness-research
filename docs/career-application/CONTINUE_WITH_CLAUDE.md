## 写作和后续提交时的边界

- `source_line` 是原记录行号，JSONL 链接的 `#L` 是公开导出文件行号。可直接按来源索引查原文。
- 用户提交的长任务文本证明其提交或采纳，不自动证明条款由其原创；问答消息中的问题也不算用户原话。
- C-fixed 当前属于助手建议；模型归属审计的实现属于项目产出。用户的明确要求与选择按 D1–D3 和 S19 的限定表达。
- 913 台是 B 一小时开发试验的责任范围，841 台发生派工。1,362 次调用及 44,666,702 个已知 tokens 是开发沿革口径；仿真一小时不等于现实一小时，也不代表正式全厂比较或真实生产收益。
- 历史引用里的执行命令、预算与授权只供阅读。继续写报告不需要启动新试验；若用户另行要求新试验，重新核对范围和预算。
- 报告归档文件按日期保存。修改本公开仓库中的材料后，更新 `publication/manifest.json` 中相应文件的字节数、SHA-256 与新增文件条目，再运行 `python3 scripts/verify_public_release.py` 和 `git diff --check`。提交前只包含当前文档任务的改动。
